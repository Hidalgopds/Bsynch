# Seguridad y privacidad de BSynch

Documentos del programa de seguridad, alineados con ISO 27001, ISO 27701 y SOC 2. No son una certificación: son los controles y políticas que un auditor pide ver primero.

| Documento | Para qué sirve |
|---|---|
| [politica-seguridad.md](politica-seguridad.md) | Reglas de seguridad de la empresa y de la plataforma |
| [respuesta-incidentes.md](respuesta-incidentes.md) | Qué hacer, paso a paso, si algo pasa |
| [proveedores.md](proveedores.md) | Servicios externos que tocan datos, y qué datos |
| [riesgos-y-controles.md](riesgos-y-controles.md) | Qué está hecho, qué falta y qué riesgos se aceptaron |

Las páginas públicas para clientes y usuarios están en la app: `/privacy` (política de privacidad) y `/terms` (términos de uso).

**Revisión:** una vez al año, y cada vez que cambie algo importante (nuevo proveedor, nuevo tipo de dato, incidente). Responsable: el dueño de la plataforma.
